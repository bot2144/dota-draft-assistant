# Security review notes

- **API keys**: entered only in Settings, stored only in the local settings cache (Tauri's app-scoped Store plugin on desktop, `localStorage` in a plain browser dev context) — never in source, never logged. `.env` is a dev-only convenience (see `.env.example`, which contains no real secret) and is git-ignored.
- **Logging**: `tauri-plugin-log` is only enabled in debug builds and logs at `Info` level from the Rust side; the JS side uses plain `console.error` for best-effort diagnostics (e.g. a failed history save) and never logs `settings.ai.apiKey` or any request/response body that could contain it.
- **SQL**: all `drafts` table access in `src/data/historyStore.ts` uses parameterized queries (`$1`, `$2`, ...) via `tauri-plugin-sql`'s `execute`/`select` — no string-concatenated SQL anywhere, so there is no SQL-injection surface even though all inputs (hero id arrays, patch string) ultimately come from user-controlled draft state.
- **Tauri capabilities**: `src-tauri/capabilities/default.json` grants only what's used — `sql:allow-load`/`allow-execute`/`allow-select` (no arbitrary-path DB loading — the URL is hardcoded to `sqlite:dota-assistant.db`), `store:default`, `fs:allow-app-write`/`allow-app-read` (app-scoped, not arbitrary filesystem paths), `http:default` (used only for the OpenDota fetch and the configured AI provider's own endpoint), `global-shortcut` (register/unregister only — it can never send input to another process, only toggle this app's own window visibility).
- **No filesystem path input from the user**: nothing in this app accepts a user-supplied filesystem path and passes it to a Tauri command — the DB path, cache file name, and store file name are all hardcoded constants.
- **Oversized-download protection**: `RemoteDataSource` only ever calls one fixed, known-shape OpenDota endpoint and JSON-parses a bounded hero-stats array; there's no user-directed arbitrary URL fetch anywhere in the app.
- **No shell command execution** from the Rust side at runtime — the only "shell-like" surface is the (Rust-native, not shelled-out) SQLite driver bundled inside `sqlx`/`libsqlite3-sys`.
- **Game-safety boundary** (repeated from the product brief, and unchanged by this expansion): nothing in this app reads game-client memory, injects into the game process, automates game input, or interacts with anti-cheat in any way. The global hotkey only shows/hides this app's own window. This was true in v1 and remains true after this expansion — no new feature in this pass touches the game process at all.
